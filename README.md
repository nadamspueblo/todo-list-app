# todo-list-app

# Learning Target
I am learning how to use forms, objects, arrays, and local storage to make a to-do list app

# Success Criteria
- I can get data from a form and store it in an object
- I can add and remove objects from an array
- I can use a for loop to iterate through an array
- I can store string values in local storage using ```localStorage.setItem(key, value)```
- I can retrieve values from local storage using ```localStorage.getItem(key)```
- I can use ```JSON.stringify(object)``` to convert an object to a string
- I can use ```JSON.parse(string)``` to convert a string to an object
